# TheStyleFolio website

The public site for TheStyleFolio, served by GitHub Pages at https://thestylefolio.com.

- `index.html` is the whole site (HTML, CSS and script in one file). The privacy policy is at `/#privacy`.
- To switch the download button and QR code to TestFlight or the App Store, set `downloadUrl` in the `SITE` block near the bottom of `index.html`.
- `CNAME` tells GitHub Pages to use thestylefolio.com.
